---
title: Starlight AI Label
description: A Starlight plugin that adds EU AI Act style disclosure badges.
---

This demo site shows the features of the `starlight-ai-label` plugin. Use the sidebar to see each
badge variant.

- [Basic](examples/basic/): AI helped, but is not the main output
- [Generated](examples/generated/): AI wrote the content in full
- [Modified](examples/modified/): human content, partly edited by AI, with an expandable scope table
- [Manual](examples/manual/): add the badge inline, with a component import
- [Badges](examples/badges/): plain SVG images, for places that cannot render a component
